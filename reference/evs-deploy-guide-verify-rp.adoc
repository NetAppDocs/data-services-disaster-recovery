= Verify that everything is working in NetApp Disaster Recovery

:hardbreaks:
:icons: font
:imagesdir: ../media/use/

[.lead]
After you add a replication plan in NetApp Disaster Recovery, verify on the Replication plans page that the plan is in the *Healthy* state before you continue.

Figure: Replication plans page image:evs-replication-plan-post-create.png[Replication plans page]
 
NetApp Disaster Recovery runs a series of tests to verify that all components, including the ONTAP cluster, vCenter clusters, and VMs, are accessible and ready for protection. This is called a compliance check, and it is run on a regular basis.

The Replication plans page shows the following information:

* Status of the last compliance check

* The replication plan’s replication state

* The name of the protected (source) site

* The list of resource groups protected by the replication plan

* The name of the failover (destination) site
