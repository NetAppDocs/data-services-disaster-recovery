= Migrate applications to another site with NetApp Disaster Recovery
:hardbreaks:
:icons: font
:imagesdir: ../media/use/

[.lead]
Using NetApp Disaster Recovery, you can migrate VMware apps on your source site to another site.

TIP: After you create the replication plan, set the recurrence in the wizard, and initiate migration, Disaster Recovery performs a verification every 30 minutes that the migration is progressing according to the plan. You can monitor the progress in the Job Monitor page. 

[NOTE]
Migration isn't currently supported for Kubernetes-based workloads. 

.Before you begin
Before you initiate migration, create a replication plan and configure it for migration. Then, the *Migrate* option appears in the Actions menu. 

.Steps

. Log in to the https://console.netapp.com/[NetApp Console^].

. From the NetApp Console left navigation, select *Protection* > *Disaster recovery*. 
. From the menu, select *Replication plans*. 
. Select the replication plan.
. On the right, select the *Actions* option image:../use/icon-horizontal-dots.png[Actions menu icon in NetApp Disaster Recovery service], hover over *Recover* then and select *Migrate*. 
. In the dialog, choose to *Take a snapshot now* to create a new snapshot for the migration or *Select* to choose an existing snapshot for the migration. 
. Enter "Migrate" in the text box to confirm the operation then select *Migrate*.
